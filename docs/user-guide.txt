XRouter·川流  LLM 分流器  安装使用说明
版本：v1.0.6    日期：2026-11-12
════════════════════════════════════════

一、应用简介
XRouter·川流 是一个装在本机的"模型分流器"。它把 AI 编码助手的请求
按"能省则省、不行就升级"的顺序自动分配给三类模型：
    第一级 免费池（智谱/硅基流动的免费模型，几乎零成本）
    第二级 Flash 模型（便宜、快）
    第三级 强模型（质量优先，前面搞不定才用）
你只需要把客户端的接口地址指向本机，费用和质量由它自动权衡。
全部配置与密钥只存在你自己电脑上，不上传任何服务器。

二、安装方法（不需要管理员权限）
1. 解压下载的压缩包。
2. 双击「双击安装.bat」。
3. 安装程序会自动完成：释放程序到
   C:\Users\<你的用户名>\AppData\Local\XRouter、
   安装运行依赖、创建桌面快捷方式、设置开机自启、启动服务。
4. 看到"安装完成"后，浏览器会自动打开日志页。

说明：
  · 全程以当前用户身份运行，不会弹出管理员权限（UAC）窗口。
  · 需要电脑已安装 Python 3.9 或更高版本。若未安装，请从
    python.org 下载，安装时勾选 "Add Python to PATH"，并选择
    "Install for me only"（仅为我安装，同样不需要管理员权限）。
  · 依赖安装需要能访问网络（pip 官方源，失败自动切清华镜像）。

三、使用方法
1. 首次配置
   打开 http://127.0.0.1:3100/settings
   填写至少一个上游：接口地址（到 /v1 为止）、API Key、模型名。
   保存后立即生效，无需重启。
2. 客户端接入
   把 AI 客户端的接口地址（Base URL）改为：
       http://127.0.0.1:3100/v1
   API Key 可随意填（除非你在上游配置里留空 Key 走透传模式）。
   模型名填任意值即可，实际模型由分流器决定。
3. 看效果
   打开 http://127.0.0.1:3100/logs
   可看到每次请求走了哪一级、用了哪个模型、耗时多少、花费多少。
   费用为按公开单价估算，不是实际账单。
4. 调优（可选）
   设置页里可以：开关免费池、调整各平台参数、添加自定义平台、
   设置强模型之间的兜底顺序（第 1 优先 / 第 2 优先）。

四、卸载方法
双击压缩包中的「双击卸载.bat」，确认后自动完成：
停止服务、移除开机自启、删除桌面快捷方式、删除程序目录。
卸载同样不需要管理员权限。

五、常见问题
1. 双击安装后提示未检测到 Python
   按第二节说明安装 Python 3.9+，勾选 Add Python to PATH。
2. 安装时依赖装不上
   多为网络问题。可手动执行：
   python -m pip install --user fastapi uvicorn httpx
3. 打开 http://127.0.0.1:3100 打不开
   双击桌面「XRouter 川流」重新启动；若端口被占用，先关闭占用
   3100 端口的程序。
4. 客户端报 401 / 无 Key
   到设置页确认上游 API Key 已填写；若使用团队网关透传模式，
   则 Key 留空，由客户端自己携带。
5. 日志太大占用磁盘
   日志超过 20MB 会自动轮转，只保留一份备份（最多约 40MB），
   也可直接删除 XRouter 目录下的 router.log。
6. 换电脑怎么迁移
   复制 XRouter 目录下的 config.json 到新电脑同名目录即可。
