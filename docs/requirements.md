# XRouter·川流 LLM 分流器 需求文档

## 一、背景

设计与开发工作中使用 AI 编码助手时，模型调用费用与响应速度是一对矛盾：强模型质量高但单价贵，免费/小模型便宜但能力有限。团队通常同时持有多个模型账号（免费额度池、低价 Flash 模型、高价强模型），但缺少一个统一的入口来按"能省则省、不行就升级"的方式自动选择模型。

XRouter·川流 解决三个具体痛点：

1. **费用不可控**：无法知道每次请求花了多少钱、有多少比例走了免费通道。
2. **切换成本高**：在 CodeBuddy 等客户端里手工切换模型繁琐，且无法在中途升级。
3. **多账号难管理**：免费额度分散在智谱、硅基流动等平台，逐个配置到客户端不现实。

面向对象：本机使用 AI 编码助手、希望降低调用成本并保留强模型兜底的开发人员。使用者只需把客户端的接口地址指向 `http://127.0.0.1:3100/v1`，其余由本工具自动完成。

## 二、逻辑流程

```
客户端请求 POST /v1/chat/completions
        │
        ├─ 读取请求特征（是否有图片、tools、上下文长度、是否多轮）
        │
        ├─ L1 免费池（可开关）
        │    逐个平台尝试 → 首个字节超时/报错 → 顺延下一个
        │    成功 → 流式回传 → 记录日志 → 结束
        │
        ├─ L2 Flash 模型（低价快速）
        │    流式回传；同时监测升级条件：
        │      空响应次数 / 输出被截断 / 指令深度过深 /
        │      工具调用签名重复 / 上游 400 / 上下文超限
        │    命中任一条件 → 中断当前流 → 升级 L3
        │
        ├─ L3 强模型（质量优先）
        │    流式回传 → 记录日志 → 结束
        │
        └─ 全部失败 → 按「兜底链」顺序重试 → 仍失败返回 502 与上游错误信息
```

异常处理：单层失败自动降级而非直接报错；升级过程中已输出的内容不回滚，仅从切换点续接；所有分支均落一行 JSON 日志。

## 三、业务逻辑

1. **配置存储**：全部配置存于程序目录 `config.json`，包括两级上游（地址/密钥/模型/高级参数）、免费池各平台参数、自定义平台、兜底链顺序。密钥只落本地文件，不上传任何服务器。
2. **接口兼容**：对客户端暴露 OpenAI 兼容接口 `/v1/chat/completions`、`/v1/models`，客户端无需改造即可接入。
3. **免费池规则**：仅调用官方定价页标注"免费"的模型；单平台首个字节超时（默认 0.35s）即切下一个；带 `tools` 的请求可设上下文上限，超过则跳过免费池（小模型工具调用易出错）。
4. **高级参数注入**：设置页可为每个上游配置 `temperature`、`top_p`、`max_tokens`、`frequency_penalty`、`presence_penalty` 及任意扩展 JSON，注入时保护 `model`/`stream`/`messages` 等核心字段不被覆盖。
5. **兜底链**：强模型之间可配置"第 1 优先 / 第 2 优先"，全部失败时按此顺序重试，保存后热生效无需重启。
6. **日志与统计**：每次请求记录时间、命中层级、实际模型、耗时、token 用量、缓存命中数；日志页汇总请求数、免费池占比、token 总量、估算费用。
7. **费用估算**：按公开单价 × 缓存命中率计算，非实际账单；日志已记录真实缓存命中的请求按真实值计算，未记录的历史请求按用户选定比例估算。
8. **日志轮转**：`router.log` 超过 20MB 自动轮转为 `router.log.1`，只保留一份备份，磁盘占用封顶约 40MB。
9. **权限要求**：安装、运行、卸载全程使用当前用户权限（程序装到 `%LOCALAPPDATA%\XRouter`，自启写 `HKCU` 注册表），**不需要管理员权限**。

## 四、验收标准

1. 双击「双击安装.bat」后无需管理员权限即可完成安装，桌面出现快捷方式，服务在 `http://127.0.0.1:3100` 可访问。
2. 首次访问自动进入配置向导，填入任一上游地址与密钥后可正常对话。
3. 客户端把 Base URL 指向 `http://127.0.0.1:3100/v1` 后，对话、流式输出、工具调用均正常。
4. 日志页能实时看到每次请求的分层路径、模型、耗时、token 与估算费用。
5. 设置页修改上游/免费池/兜底链并保存后立即生效，无需重启。
6. 免费池某平台故障时请求自动顺延，客户端不感知报错。
7. 双击「双击卸载.bat」后服务停止、自启与快捷方式移除、程序目录删除，无残留。
8. 全程不弹 UAC 提权窗口。
