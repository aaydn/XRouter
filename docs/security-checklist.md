## 说明

1. **数据流向**：本工具是本机反向代理，只做一件事——把客户端请求转发到用户自己配置的模型接口，并把响应流式回传。不采集、不上报、不外发任何用户数据；无统计埋点、无远程心跳。
2. **本地留存**：仅在本机程序目录写入两类文件——`config.json`（配置与密钥）、`router.log`（请求日志，含提示词用量统计，不含完整对话内容）。日志超过 20MB 自动轮转，只保留一份备份，用户可随时删除。
3. **监听范围**：默认只监听 `127.0.0.1:3100`，不对局域网开放，其他机器无法访问。
4. **权限模型**：安装、运行、卸载全程使用当前用户权限，不申请管理员权限、不写系统目录、不注册系统服务、不修改系统级环境变量；自启项写在 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，卸载时删除。
5. **安装包自检**：发行包内只有三个文件（双击安装、双击卸载、使用说明）。安装器内的程序载荷以 base64 形式内嵌，解包到 `%LOCALAPPDATA%\XRouter`，不写注册表以外的任何系统位置，不执行下载动作（依赖安装除外，走 pip 官方源或清华镜像）。
6. **第三方依赖**：仅 `fastapi`、`uvicorn`、`httpx` 三个开源库，均为公开 PyPI 包，无私有源、无编译型组件。
